# Jelajah Sae Kota Blitar

Situs multi-halaman: index, destinasi, menginap, kuliner, blitar-raya, peta, informasi. Detail destinasi tampil sebagai pop-up.

Semua data ada di `assets/js/data.js` (D, INFO, HOTELS, FOODS, OLEH, pos). Setiap destinasi punya jam buka, tiket, parkir, tips, tombol Google Maps dan Rute.

Harga bertanda * atau "Cek harga" belum terverifikasi: isi di `INFO` (kolom `t` dan `tc`).

GitHub Pages: Settings > Pages > branch main, folder root.
